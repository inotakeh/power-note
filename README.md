# ぼくのパワーノート

ごはんや べんきょう、おてつだいを きろくすると ヒーローが そだつ、こども用の きろくアプリです。

- きろくすると「あたま・あし・うで・からだ・こころ」の 5つの ちからが あがります
- きろくや バトルで コインが たまり、けん・たて・よろい・おまもりを かえます
- バトルチケットで ミニゲームバトル(クイズ・すばやさ・こうげき・ガード・おぼえる)が できます
- サッカー じこベスト、きょうの きもち、なかなおり、きょうの しつもん、きょうだいで ミッション も あります
- やさしい ことと すきな ことには コインを つけません。くらべるのは まえの じぶん です

1つの `index.html` だけで うごきます。きろくは つかっている たんまつの なか(localStorage)にだけ ほぞんされ、どこにも おくられません。

「せってい」の「おうちの ひとの メニュー」から、ファイルへの かきだし・ファイルから もどす・自動の控えから戻す が できます。iPhone では ホーム画面に 追加した アイコンから ひらいて ください(Safari の タブとは きろくが べつに なります)。
